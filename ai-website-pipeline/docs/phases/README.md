# Phase files - how to use

1. Put SPEC.md (Writing_v2.txt) in the repository root.
2. Start a coding agent session. Give it: 00_COMMON_RULES.md + 00_phase0_architecture_and_stack.md.
3. Read what it produces. Approve (or correct) the architecture and stack.
4. Give it 00_COMMON_RULES.md + the next phase file. Repeat, one phase at a time.
5. Never skip the report-and-approve step between phases.

Order:
Phase 0 Architecture and stack
Phase 1 Instagram and conversations
Phase 2 Requirements Agent
Phase 3 Specification and client approval
Phase 4 Spec Auditor
Phase 5 Main Coding Agent (landing page first)
Phase 6 Code Checker  <- first full vertical slice is complete here
Phase 7 Team Panel
Phase 8 Advanced (Design Swap, more website types, ...)
